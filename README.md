# 🎮 Roblox 3D 方塊床戰 (Roblox BedWars 3D)

一款基於 **Three.js** 與 **React 19** 打造的 3D 體素風格多人島嶼床戰網頁遊戲，靈感源自 Minecraft 與 Roblox 的經典床戰 (BedWars) 玩法。

玩家將代表**紅隊**出征，在懸浮空中的群島地圖中與藍隊、綠隊、黃隊展開激烈的資源爭奪與攻防戰。採集發電機資源、搭建空中橋樑、在補給商店購置神裝與戰術道具、升級全隊科技，並在守護自家床位的同時拆毀敵方床位，贏得最後的勝利！

---

## 🌟 遊戲核心特色

### 1. 🏰 4 隊浮島對抗與床位重生機制
- **陣營配置**：紅隊（玩家陣營）、藍隊、綠隊、黃隊，每隊配置 2 名成員（共 8 人即時戰鬥）。
- **床位存活**：只要己方床位完好無損，陣亡後可在 5 秒內無限次原地復活。
- **床位摧毀**：一旦隊伍床位被敵方摧毀，該隊員陣亡將觸發「最終擊殺 (Final Kill)」，直接淘汰出局！
- **獲勝條件**：摧毀所有敵隊床位並淘汰所有敵方玩家。

### 2. 🌉 極速搭橋與邊界防摔系統 (Speed Bridging & Safe Sneak)
- **高速鋪路 (Speed Bridging)**：長按滑鼠右鍵即可快速連續向後、向前或向兩側鋪設方塊橋樑。
- **全像投影預覽**：手持方塊時，視線對準的有效附著面會即時顯示半透明發光預覽方塊。
- **`Shift` 潛行防摔**：按住 Shift 鍵會啟動安全邊界限制，角色移動時絕不滑落虛空，搭橋更安心。
- **原地跳躍墊高**：按住空白鍵跳躍並朝腳下點擊右鍵即可連續向上疊高，迅速佔領制高點。

### 3. 💎 多層次島嶼資源與發電機系統
- **基地發電機**：基地內部定期產出**鐵錠 (Iron)**與**金錠 (Gold)**，用於購買基礎方塊、裝備與工具。
- **鑽石角島 (4 座)**：地圖四個對角的外圍浮島，定期產出**鑽石 (Diamond)**，用於全隊科技附魔。
- **中央神聖主島**：地圖正中央的大型島嶼，刷新稀有**綠寶石 (Emerald)**，用於兌換終極神裝、黑曜石與瞬移珍珠。

### 4. 🛒 補給商店與戰隊科技升級
- **持久性裝備**：鎖子甲、鐵甲、鑽石甲以及防具剪刀在購買後**死亡不會掉落**，永久生效。
- **戰術消耗品**：
  - **烈焰彈 (Fireball)**：右鍵遠程投擲，命中產生強力擊退與範圍爆炸。
  - **瞬移末影珍珠 (Ender Pearl)**：右鍵拋擲後瞬移至落點，偷襲破床或高空脫困神技。
  - **TNT 炸藥**：點燃延時爆炸，快速破壞敵方方塊防禦。
  - **金蘋果 (Golden Apple)**：右鍵食用迅速恢復大量生命值。
- **全隊科技 (鑽石解鎖)**：
  - ⚔️ **鋒利附魔 (Sharpness)**：全隊近戰武器傷害提升。
  - 🛡️ **保護附魔 (Protection)**：全隊受到傷害減免提升。
  - ⚡ **鍛造升級 (Forge Upgrade)**：加快基地發電機鐵錠與金錠生成速度。

### 5. 🤖 智慧 AI 機器人系統
- 敵方與友軍 AI 具備獨立的狀態機與戰術路徑規劃。
- AI 會自動收集資源、至商店購買防具武器、搭建橋樑、保護床位並主動出擊攻打敵方基地。

### 6. 🎨 零外部依賴的程式化引擎
- **純 Procedural 紋理生成**：羊毛編織紋理、橡木木紋、黑曜石宇宙結晶、立體草地花朵皆由 Canvas 程式化生成，加載極速。
- **Web Audio API 原生音效**：刀劍揮砍、肉搏受擊、警報破床、爆炸轟鳴與勝利號角均即時合成，免去外部音效載入延遲。
- **雙重視角**：自由切換第一人稱 (FPS) 與第三人稱 (越肩视角)。
- **全平台適配**：電腦鍵鼠操作 + 行動端專用虛擬搖桿與觸控介面。

## 🕹️ 操作指南

### 💻 PC 電腦端操作

| 按鍵 / 輸入 | 操作說明 |
| :--- | :--- |
| **W / A / S / D** | 前進、後退、向左移動、向右移動（精準跟隨相機視角） |
| **Space 空白鍵** | 跳躍 / 向上連續跳躍墊高 |
| **Shift 鍵** | 潛行防摔（開啟邊界安全鎖定，絕不掉入虛空） |
| **滑鼠移動** | 環顧四周 / 調整視角朝向 |
| **滑鼠左鍵 (長按)** | 近戰揮劍攻擊 / 挖掘方塊 / 拆除敵方床位 |
| **滑鼠右鍵 (長按)** | 連續極速搭橋 / 放置方塊 / 投擲烈焰彈與珍珠 / 食用金蘋果 |
| **1 ~ 8 數字鍵** / **滾輪** | 切換快捷物品欄 (Hotbar) |
| **E 鍵** | 打開 / 關閉基地補給商店 |
| **V 鍵** | 切換視角（第一人稱 FPS ⇄ 第三人稱 越肩視角） |
| **H 鍵** | 查看玩法規則與按鍵指南 |
| **ESC / 點擊畫面** | 釋放或重新鎖定滑鼠指標視角 |

### 📱 手機 / 平板觸控操作

- **左下角虛擬搖桿**：拖動控制角色 360 度移動。
- **右側觸控螢幕**：滑動任意區域旋轉相機視角。
- **專屬動作按鈕**：
  - ⚔️ **Attack (攻擊)**：長按揮砍或挖掘方塊。
  - 🧱 **Build (建造)**：長按快速搭橋與放置方塊。
  - 🦘 **Jump (跳躍)**：跳躍或向上墊高。
  - 🛡️ **Sneak (潛行)**：切換防摔鎖定狀態。
  - 🛍️ **Shop (商店)**：一鍵開啟補給物資介面。
  - 👁️ **Cam (視角)**：切換第一人稱與第三人稱。

## 🚀 快速開始與本地開發

### 1. 環境需求
請確保您的電腦已安裝：
- **Node.js**：v18.0.0 以上
- **npm**：v9.0.0 以上 (或 yarn / pnpm / bun)

### 2. 安裝步驟

```bash
# 1. 進入專案目錄
cd bedwars

# 2. 安裝相依套件
npm install

# 3. 啟動本地開發伺服器
npm run dev
```

啟動後，在瀏覽器打開終端機提示的網址（通常為 `http://localhost:3000`），即可直接進入遊戲！

### 3. 其他腳本指令

```bash
# 靜態 TypeScript 型別與語法檢查
npm run lint

# 打包生產發布版本 (產出至 dist/ 目錄)
npm run build

# 預覽打包後的生產版本
npm run preview
```

## 💡 戰術小撇步 (Tips & Tricks)

1. **開局搭橋**：開局後先在基地發電機拾取 16~32 塊鐵錠，立即在商店購買羊毛方塊，搶先鋪路至旁邊的鑽石島！
2. **保護床位**：單純用羊毛包床容易被剪刀瞬間剪破，儘早使用木板或前往中央島採集綠寶石購買黑曜石保護床位。
3. **安全搭橋技巧**：長按 Shift 防摔，面向後方邊界長按右鍵，即可實現超高速穩固搭橋。
4. **絕地反擊**：手持烈焰彈對準衝過來的敵方玩家，將其炸飛至虛空即可輕鬆完成擊殺。
5. **護甲保全**：優先升級鐵甲或鑽石甲，因為護甲在死亡重生後依然會保留，性價比極高！
